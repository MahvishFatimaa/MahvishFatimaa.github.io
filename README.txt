PUBLIC ASSETS
=============

Drop your files here. Anything in /public is served at the site root,
so public/profile.jpg is reachable in code as "/profile.jpg".

What to add:
  1. profile.jpg        -> your real photo (square works best, ~600x600)
  2. profile-ascii.txt  -> the ASCII version of your photo (already stubbed below)

Replace the contents of profile-ascii.txt with your generated ASCII art.
The site will read and display it. No code changes needed to swap either file.
